## Project Overview

- **Type:** Fullstack（Next.js 前端 + FastAPI 后端 + 子进程 AI 引擎），单体双包仓库
- **Languages:** Python 234 个源文件（≈52%）、TypeScript/TSX 225 个（≈48%）
- **Frameworks:**
  - 前端：Next.js 15 App Router（RSC 首屏 + 客户端交互）· React 19 · Tailwind CSS 4 · TanStack Query · zustand · lightweight-charts · echarts · Radix UI
  - 后端：FastAPI · SQLAlchemy 2 + Alembic · SQLite（WAL + 外键）· uvicorn **必须 `--workers 1`**
  - 引擎：`aragon exec --output-format stream-json --result-schema …` 子进程（`api/app/agent/`）
- **Entry Points:** `api/app/main.py`（`create_app`）· `web/app/layout.tsx` + `web/app/page.tsx` · `web/app/[symbol]/page.tsx`（工作台）· `api/app/cli.py`（离线运维 CLI）
- **核心不变量：**
  - API 单 worker（`main.py::assert_single_worker()` 启动即拒绝），因为生成编排是进程内 `asyncio` 任务 + 内存订阅者队列。
  - Schema 唯一真源是 Alembic；`create_all` 只允许出现在 `api/tests/conftest.py`。
  - 报告不是 HTML，而是 `aragon.research.report/v1` 结构化文档（12 种判别联合块），由 `--result-schema` 校验。

## 运行态目录约定

本项目**已有**自己的运行目录约定，全部已在 `.gitignore` 中；索引只登记，不改动：

| 目录 | 用途 | 生命周期 | git 跟踪 |
|------|------|----------|----------|
| `api/workspace/runs/<runId>/` | 每次生成 run 的快照、提示词、NDJSON 审计 | 按保留期清理 | 已忽略 |
| `api/workspace/asks/` | `deep` 追问的工作区（可从 `reports.doc_json` 重建） | 运行时重建 | 已忽略 |
| `api/workspace/.tmp/` | 临时中转 | 随时可删 | 已忽略 |
| `api/data/app.db` | SQLite 运行时库（WAL） | 长期保留 | 已忽略 |
| `.run/` | `start-all.ps1` / `stop-all.ps1` 的 PID 与分文件日志 | 每次启停重写 | 已忽略（`/.run/`） |
| `.agentmesh/` | agent 编排运行态（图状态、任务提示词、报告） | 工具态，长期保留 | 已忽略 |
| `.claude-index/` | 本索引与 `graph.json` | 每次 regenerate 重写 | 有意跟踪 |

> 一次性脚手架请落在 `.agentmesh/scratch/`（已随 `.agentmesh/` 忽略），任务结束即删；
> 不要往仓库根新增 `runs/` 或临时脚本。
