# 品牌图形生成与接入记录

日期：2026-11-20。使用内置 `image_gen.imagegen`（GPT Image 生图能力），
没有调用 Gemini/Nano Banana、外部模型 SDK 或 CLI 回退。全部构图与修订
由生图工具完成；本地仅使用已有 Pillow 确定性缩放、PNG 编码及验收联图。

## 提示词

首轮三枚候选每次独立一张，均设置 `transparent_background=true`，不传
参考图片参数。主提示词如下：

> Use case: logo-brand. 为 Aragon Research Terminal 投研工作台设计原创正式品牌图形。图形方向是“切面透镜”：三个厚实、克制的圆角几何切面围合一个清晰的负形焦点，表达研究证据汇聚与精准判断。专业软件产品的简洁几何气质，平面、轮廓稳定、视觉居中、留白均衡，缩小到 24 像素仍能辨认。主色使用项目绿色 #3ecf8e，可有极少量蓝色 #4c9aff 辅助，主体在深色 #0b0c0e 和浅色 #ffffff 背景上都清楚。输出一枚独立图形，真实透明背景，1024x1024 正方形高分辨率。不要文字、字母、数字、水印、样机、圆角应用底板、金融货币符号、机器人头像、复杂渐变、发光或 3D 立体效果。不得模仿任何已有公司的商标。

第二枚在主提示词后增加“本候选仅调整切面间距：略宽的清晰缝隙”；
第三枚增加“本候选仅调整负形开口：稍扩大负形焦点的开口”。
